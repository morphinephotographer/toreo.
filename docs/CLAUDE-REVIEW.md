# Анализ Toreo в Claude

Toreo 0.3.5 (сборка 8) — клиент BitTorrent для Apple Silicon и macOS 26+. Это приложение строки меню с одной панелью Liquid Glass. Встроенный движок использует Transmission 4.1.4. В архиве для анализа лежат исходники Toreo, документация, снимки на тестовых данных и журнал проверок интерфейса. Установочная сборка прилагается к тому же релизу отдельно.

## Карта проекта

| Файлы | Что смотреть |
| --- | --- |
| `Sources/App.swift`, `Sources/Indicators.swift` | Запуск, завершение, привязка и размеры панели |
| `Sources/MenuBarIcon.swift`, `Sources/DockIcon.swift`, `tools/compile-dock-alternate.sh` | Анимация статуса, очередь завершений, Reduce Motion, шесть вариантов Dock и сохранение выбора |
| `Sources/MenuPanel.swift`, `Sources/Views.swift` | Основная панель, поиск, действия карточек, настройки, импорт и список файлов |
| `Sources/Store.swift`, `Sources/DownloadSearch.swift` | Состояние интерфейса, импорт и автоимпорт, очередь запросов, поиск, удаление |
| `Sources/Engine.swift`, `Engine/` | Актор движка, мост к libtransmission, работа с данными торрентов |
| `Sources/Localization.swift`, `Icon/`, `Info.plist` | Локализация, иконка и метаданные сборки |
| `Sources/Snapshot.swift`, `Sources/AppCheck.swift`, `tools/engine-check.py` | Проверки интерфейса, приложения и движка |

`README.md` описывает текущее поведение. `TOREO-PROJECT.md` и `docs/BRIEF.md` содержат исторический контекст. При расхождениях проверяйте поведение по исходникам и тестам.

## Проверка на Mac

1. Пересоберите приложение по инструкции в `README.md`.
2. Для снимков и проверок панели запустите `RILL_SNAPSHOT_DIR=/tmp/toreo-snapshots ./toreo..app/Contents/MacOS/Toreo`. Тестовый режим не запускает сетевую сессию.
3. Для проверок импорта и завершения используйте `RILL_APP_CHECK` или `RILL_QUIT_CHECK` с собственным тестовым `.torrent` и задайте `RILL_STORE` на отдельную временную папку. Сценарии сетевой проверки описаны в `README.md`.

В последней версии кнопка magnet всегда открывает поле ввода. Расширенный импорт и список файлов используют общие карточки, стеклянные кнопки и сетку основной панели. Обычное добавление файла или magnet запускает скачивание сразу. Снимок расширенной формы подготовлен на тестовых данных.

Для отдельной проверки значка в реальной строке меню запустите `RILL_STATUS_SNAPSHOT_DIR=/tmp/toreo-status ./toreo..app/Contents/MacOS/Toreo`. Тест использует синтетические состояния, сохраняет снимки области значка и проверяет штатное открытие панели.
